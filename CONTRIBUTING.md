# Contributing

Thanks for helping. Corrections to ranges, sources and species are the most
useful contributions of all.

## The data rules

Read [CLAUDE.md](CLAUDE.md) and the README first. Above all: **nothing is added
or removed without a verifiable source.** Every `gbif.include` / `gbif.exclude`
needs a URL or citation you have actually checked. Run `npm run check` before
opening a pull request; CI runs the same checks.
